# Портфолио системного аналитика

Архитектурные кейсы и артефакты проектирования: формализация требований, модели данных (ERD), конечные автоматы (State Machine), асинхронные и синхронные интеграции (REST API, Webhooks, OpenAPI 3.0) и обработка краевых сценариев.

> **Дисклеймер.** Все кейсы очищены от коммерческой тайны, собраны на синтетических данных и обобщённых сценариях. Названия внешних систем и реквизиты условные.

## Содержание

| # | Кейс | Ключевые архитектурные акценты |
|---|------|--------------|
| [01](./case-01-meeting-room-management) | Управление расписанием и ресурсами (RBAC + конкурентный доступ) | Мультиарендная ролевая модель (изоляция по юрлицам), защита слотов от двойного бронирования (Redis lock + PostgreSQL `EXCLUDE USING gist`), конечный автомат статусов |
| [02](./case-02-booking-crm-sync) | Двусторонняя синхронизация онлайн-записи с CRM | Событийный обмен по Webhooks, паттерн Transactional Inbox, идемпотентность, защита от обратного эха, разрешение конфликтов на уровне полей, контракт [OpenAPI 3.0](./case-02-booking-crm-sync/openapi.yaml) |
| [03](./case-03-crm-data-pull) | Инкрементальный ETL и сверка распределённых реестров | Delta-выгрузка по составному курсору `(updated_at, id)` с окном перекрытия, карантин битых записей (DLQ), контроль качества данных в PostgreSQL |
| [04](./case-04-report-automation) | Автоматизация формирования регламентной отчётности (КНД 1151156) | Проектирование и разработка микросервиса ([tax-reporter](https://github.com/vfedorov-sa/tax-reporter)): REST API, 18 контрольных проверок, генерация PDF и отправка пакетов через шлюз |

## Стек и инструменты проектирования

* **Нотации и моделирование:** BPMN 2.0, UML (Sequence, State Machine), ER-диаграммы.
* **Спецификации и контракты:** OpenAPI 3.0 / Swagger, JSON Schema, Markdown, Mermaid, Draw.io.
* **Технический стек:** PostgreSQL (CTE, оконные функции, GIST-ограничения), Redis, REST API, Webhooks, Apache Kafka, Python (FastAPI, Pydantic, pandas, pypdf).
